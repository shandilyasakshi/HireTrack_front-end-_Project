HireTrack 🚀
Track. Apply. Get Hired.

HireTrack is a modern internship and job application tracking platform built to help students organize their applications, track progress, manage deadlines, and stay on top of their career opportunities.

Features:

1. 📊 Application dashboard with key statistics
2. 📋 Add and manage internship/job applications
3. 🔎 Search and filter applications
4. 🔄 Track application status
5. 📅 Monitor upcoming deadlines
6. 📝 Store application notes and details
7. 👤 Profile and settings management
8. 🌙 Light/Dark mode
9. 📱 Responsive design

🛠️ Tech Stack:

1. HTML5 – Structure
2. CSS – UI/UX and responsive design
3. JavaScript – Interactions and functionality
4. LocalStorage – Demo data persistence
